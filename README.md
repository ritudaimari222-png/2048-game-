# 2048 Android App

Android Studio project wrapping the playable 2048 game in a native Android WebView container.

## Build APK
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. The debug APK will be under `app/build/outputs/apk/debug/`.

Application ID: com.example.game2048
Version: 1.0 (1)
Minimum Android: 6.0 (API 23)
Target Android: 15 (API 35)
